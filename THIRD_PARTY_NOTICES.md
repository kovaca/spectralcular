# Third-party notices

Spectralcular is MIT licensed (see `LICENSE`). The data, palettes and fonts it
uses carry their own terms, summarized here. Anything printed from this
pipeline should reproduce the attributions below in its colophon; `spectralcular
print` derives the colophon from what a book actually uses.

## Satellite imagery

- **Sentinel-2 L2A** via the Element 84 Earth Search STAC API. Copernicus data is
  free to use with attribution: *"Contains modified Copernicus Sentinel data
  [year], processed by ESA."* (`config/book_specs.yaml` → `attribution`).
- **Scene Classification (SCL)** masks are part of the same product.
- **Landsat 8/9 Collection 2 Level 2** via the Microsoft Planetary Computer STAC API
  (`landsat-c2-l2`). Landsat data are in the public domain; USGS requests the
  credit *"Landsat imagery courtesy of the U.S. Geological Survey."* The QA_PIXEL
  quality band is part of the same product.
- **Sentinel-1 RTC** (radiometrically terrain corrected GRD, produced by Microsoft)
  via the Planetary Computer STAC API (`sentinel-1-rtc`). Copernicus data, same
  attribution as Sentinel-2.
- **Planetary Computer** asset access is governed by Microsoft's Planetary Computer
  terms of use (https://planetarycomputer.microsoft.com/terms); assets are read
  with anonymous, short-lived SAS tokens.

## Basemaps and reference data

- **Natural Earth** 1:110m land polygons (`src/spectralcular/_data/ne_110m_land.geojson`) — public domain.
- **OpenStreetMap** raster tiles for the scene locator — © OpenStreetMap contributors,
  ODbL. Tile requests follow the OSM tile usage policy; set `SPECTRALCULAR_CONTACT`
  so the User-Agent identifies you.
- **OpenFreeMap** vector tiles (web picker basemap) — OpenStreetMap data, ODbL.
- **Photon** geocoder by komoot (web picker place search, photon.komoot.io) —
  OpenStreetMap data, ODbL.

## Spectral indices

- **spyndex** / **Awesome Spectral Indices** (David Montero) — MIT. Every index
  formula and reference on a specimen card comes from this catalog.

## Fonts

- **DejaVu** Serif and Sans Mono (bundled with matplotlib) are embedded in the
  plate pages — Bitstream Vera license with DejaVu changes in the public domain
  (https://dejavu-fonts.github.io/License.html).
- The specimen cards and front matter name system fonts first (Iowan Old Style,
  Menlo on macOS) and fall back to generic serif / monospace; check the license
  of whatever your system substitutes before printing commercially.
