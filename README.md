# Spectralcular

Satellite spectral indices × colormaps, composed into a print-ready book.

Pick a place, a satellite scene, a spectral index and a colormap in the browser;
a reproducible pipeline turns each choice into a two-page spread — the scene
printed to the edge of the paper, and a specimen card facing it with the
formula, the bands, the true color of the same frame, the colormap's lightness,
chroma and hue, and a histogram of the values on the page — then assembles the
spreads, front matter and cover into files a print-on-demand service accepts.

```
web picker ─▶ selection.json ─▶ spectralcular import · lock · build ─▶ spectralcular print ─▶ interior + cover PDFs
```

**Spectralcular Scenery**, the book this repo was built for, is reproducible
from [`examples/spectralcular-scenery/`](examples/spectralcular-scenery/): 100
scenes of 96 places, 76 indices and 80 colormaps.

## Install

Python 3.11 or 3.12 with [`uv`](https://docs.astral.sh/uv/), and Pango for
WeasyPrint (`brew install pango`, or `libpango-1.0-0 libpangoft2-1.0-0` on
Debian/Ubuntu). The web picker needs Node 24 and pnpm.

```bash
uv sync
uv run pytest -q          # offline unit tests
uv run spectralcular --help    # `gb` is a short alias
```

Imagery comes from public STAC catalogs with no credentials: Sentinel-2 L2A from
Element 84 Earth Search, and Landsat 8/9 (thermal indices) and Sentinel-1 RTC
(radar indices) from Microsoft Planetary Computer. Set `SPECTRALCULAR_CONTACT`
(an email or URL) so the OpenStreetMap tile requests for locator maps identify
you.

## Build the example book

```bash
examples/spectralcular-scenery/build.sh ~/books/spectralcular-scenery
```

This creates a project folder, imports the selection, locks the order, builds
all 100 spreads and writes `output/print/` — the interior and cover PDFs and a
preflight report. It needs about 25 GB of disk and an hour or two on a home
connection; re-running resumes.

## Make your own

**1. Compose in the browser.** [`web/`](web/) is a static app, deployed at
<https://kovaca.github.io/spectralcular/>. Browse the location pool or search
any place, find a clear scene, place a rotatable page frame (with the print
resolution as you zoom), preview any index and colormap live from the
cloud-optimized GeoTIFFs, and keep an ordered list of scenes. Your work stays in
the browser; **Export** downloads `<book>.selection.json`. To run it locally:
`cd web && pnpm install && pnpm dev`.

**2. Build the book** in a project folder, which holds one book's config, caches
and output (keep it out of the checkout):

```bash
uv run spectralcular init ~/books/mine                 # config copied from this checkout
export SPECTRALCULAR_PROJECT_DIR=~/books/mine          # or pass --project-dir
uv run spectralcular import ~/Downloads/mine.selection.json
uv run spectralcular candidates lock --force
uv run spectralcular build --skip-existing --keep-going
uv run spectralcular print                             # → output/print/
```

Edit `config/book.yaml` in the project for the title, author, introduction and
cover text. `print` finishes the interior to Lulu's file rules (sRGB, no
transparency, 300 ppi images, embedded fonts, trim and bleed boxes), renders the
cover with the spine sized for the page count, and writes `preflight.md`. The
colophon's credits — imagery years, data sources, every colormap collection and
its license — are derived from the scenes.

[`docs/process.md`](docs/process.md) covers the rest: the print specification
and why, curating from the pools at scale with contact sheets, and rendering a
single spread from a config (`examples/spreads/`).

## Colormaps

The pool holds ~370 palettes: palettize presets plus a vendored snapshot of the
[colorcurio.us](https://colorcurio.us/colormaps) catalog with upstream
attribution, license, tags and perceptual / color-vision metrics. Add your own by
pasting stops into `config/pool/colormaps.yaml` (see
[`CONTRIBUTING.md`](CONTRIBUTING.md)).

## Layout

| Path | What |
|---|---|
| `config/` | the template every project starts from: print spec (`book_specs.yaml`), book copy (`book.yaml`), pools of locations, indices and colormaps (`pool/`), and reference data the picker reads |
| `src/spectralcular/` | the pipeline and CLI |
| `web/` | the picker ([`web/README.md`](web/README.md)); `web/src/lib/data/` is generated by `spectralcular export-web` |
| `examples/` | the example book, and single-spread configs |
| `manifests/` | selections to build with the *Build book from selection* GitHub workflow |
| `tools/` | the locations-pool seeder |
| `docs/` | [`process.md`](docs/process.md) (how a book gets made), [`DESIGN.md`](docs/DESIGN.md) (visual spec) |

## Status

The print files follow Lulu's published presets and pass the built-in preflight,
but have not yet been through Lulu's upload check or a printed proof. Print
gamut is unverified: there is no ICC soft-proof, so the review sheets offer a
chroma-based hint only. Next: a printed proof, an ICC soft-proof of every
colormap, and an optional Lulu Print API step on the build workflow.
